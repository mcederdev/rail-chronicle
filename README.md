# Rail Chronicle website

The public website for Rail Chronicle, an idle railway game for iPhone. GitHub Pages serves it at https://mcederdev.github.io/rail-chronicle/.

Marketing and portfolio material only. The game itself lives in a separate private repository; never put game code here.

Status: in development (not released yet). When the app is live, replace the "In development" status box in `index.html` with Apple's official App Store badge linked to the app, and add the `apple-itunes-app` meta tag (placeholder comment in the head).
